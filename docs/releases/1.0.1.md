# Native 1.0.1

Windows x64 修订版，沿用 1.0.0 的安装身份和用户资料目录。

## 更新

- 修复下载任务“打开所在文件夹”：任务 ID 校验与后端的 32 位十六进制 ID 一致。
- 同步旧目录测试数据，并补充文件定位、无文件时打开目录、非法 ID 和越界路径回归。
- 更新第三方 NOTICE。未提交的本地下载及 Lite 恢复修改不属于此版本。

## 构建与限制

计划使用 GitHub Actions 的 Native Release 工作流构建 Windows NSIS，并执行安装包解包审核。正式发布的版本身份、构建结果和附件哈希以 Release 记录为准。

安装器未签名。自动化测试不使用真实 Apple 账号或商业媒体，不保证所有账号和地区可用。第三方材料状态见[核查说明](../compliance/native-status.md)，部分 Debian 源码资料不等于整个安装包的完整对应源码。
