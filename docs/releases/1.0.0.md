# Native 1.0.0

Windows x64 原生桌面版。[查看 Release 与校验文件](https://github.com/Andrew05213/applemusic-downloader-native/releases/tag/v1.0.0)。

本页说明版本功能和兼容边界；正式发布状态、目标提交、安装包 SHA-256 及实际验证记录，以该 Release 页面为准。

## 功能

- 原生账号和受信任设备验证码登录，不依赖 WSL 或内置官方网页。
- 首页推荐、搜索、歌单、专辑与音乐人详情；页面缓存和预加载。
- AAC 分片流式播放与进度拖动，完整播放不可用时回退试听。
- 默认 ALAC 下载，支持队列并发、速度与进度、失败重试、保存目录和文件名模板。
- 任务记录/文件分别删除，文件夹定位和安全文件身份校验。

## 安装与校验

安装包名称为 `AppleMusicDownloader-1.0.0-Setup.exe`，随附同名 `.sha256` 文件。
未签名，Windows 可能显示未知发布者。核对下载来源及校验和，不关闭系统安全防护。

```powershell
Get-FileHash -Algorithm SHA256 .\AppleMusicDownloader-1.0.0-Setup.exe
```

媒体能力受有效账号、订阅与地区限制。自动/隔离测试不代表每个真实账号均已验收。
覆盖旧仓库 2.0.0 安装的版本回退及现有账号资料迁移，不作为本次验证已完成的承诺。
