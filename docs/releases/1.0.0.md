## 功能

- 原生账号与受信任设备验证码登录，不需要 WSL 或内置官方网页。
- 推荐、搜索、歌单、专辑与音乐人详情，支持缓存与预加载。
- AAC 分片流式播放与拖动，完整播放不可用时回退试听。
- 默认 ALAC 下载、并发队列、实时速度和进度、失败重试、目录选择与文件名模板。
- 任务/文件分别删除、文件夹定位与安全文件身份校验。

## 验证与限制

发布提交的 [CI](https://github.com/Andrew05213/applemusic-downloader-native/actions/runs/41212466474) 通过。安装器解包后 279 个文件与构建输出一致，198 项资源回执核验通过；实际应用通过隔离启动、目录选择、诊断及合成 AAC 拖动测试，服务通过文件删除和失败重试测试。

详细结果见 Release 附件 `verification-1.0.0.json`。本次未使用真实 Apple 账号或商业媒体；账号、订阅和地区可用性不属于自动化验收保证。

安装包未签名。核对来源及附带的 SHA-256，不关闭系统安全防护：

```powershell
Get-FileHash -Algorithm SHA256 .\AppleMusicDownloader-1.0.0-Setup.exe
```

极深的 Windows 资料路径可能导致 QEMU 无法读取 BIOS，验收中复现过 265 字符路径失败。覆盖前身 2.0.0 的降版本安装和账号资料迁移未验收，旧版用户先备份；保留标识见[兼容说明](../development/compatibility.md)。
