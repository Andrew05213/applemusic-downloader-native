# 2.0.0 私有测试构建

> 历史记录：以下内容保留当时的实现、命令与验收语境，不代表当前发布状态。当前指南见[文档导航](../README.md)，不要直接用本页旧命令安装或发布 2.0。

仅供此私有仓库的授权协作者测试。`publicReleaseAllowed=false` 保持不变；不得将安装包公开上传或重新分发。源码许可不等于 Android/Apple 等运行材料的再分发授权。

## 本次内容

- 原生 Windows 界面与 Lite/QEMU 运行组件，不要求用户安装 WSL、Docker 或打开内置官方网页。
- 原生设备验证码登录、会话恢复及保留阶段错误的诊断导出；短信验证入口已撤回。
- AAC 分片流式播放，首段缓冲后开始，拖动直接加载目标位置；不可用时明确回退到试听。
- 下载默认 ALAC；下载与处理 1:1 进度、速度显示、任务标题、具体失败原因、并发请求排队。
- M4A 分片索引、文件头时长和标签兼容处理；任务文件删除、空目录清理、选择下载路径和打开任务目录。
- 侧栏、搜索排序、艺人/专辑详情、推荐、窗口化启动动画和可调缓存。
- 安装向导支持选择安装位置，保留原有应用身份、会话与任务数据。
- 当前 2.0 文档导航、历史构建可恢复归档和统一的新构建输出目录。
