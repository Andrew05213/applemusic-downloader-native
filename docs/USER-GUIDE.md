# Native 1.0 用户指南

## 安装与登录

本仓库尚未提供 1.0.0 安装包，以下说明针对现有功能。后续从[本仓库 Releases](https://github.com/Andrew05213/applemusic-downloader-native/releases)下载 Windows x64 安装包，并按[首页说明](../README.md#下载与安装)核对附带的 SHA-256。
安装包未签名；请确认下载来源，不要为了安装而关闭安全软件。
运行软件后使用原生登录窗口；需要二次验证时，在已登录同一 Apple 账户的受信任设备上批准登录，填写本次六位验证码。
当前不提供软件内发送短信的登录流程。不需要安装 WSL、Docker 或内置 Apple 网页。

## 播放与下载

- 点击封面或标题进入详情；左上角返回上一页。
- 单一播放入口优先尝试完整播放；不可用时可能回退到试听，查看播放器的模式提示。
- 下载默认 ALAC。完整播放、下载及资源可用性受账号、订阅和地区限制。
- 在“设置与状态”中选择下载文件夹、默认音质和并行数，并保存设置。
- 下载任务展示名称、进度、速度和具体错误；文件夹按钮用于定位该任务的文件。
- “仅删除任务”与“删除任务与文件”含义不同，删除前确认是否保留媒体文件。
- 缓存默认上限 500 MB，可在设置中调整或清理；这不是下载目录容量上限。

## 遇到问题

先记录软件版本、操作步骤、歌曲或专辑链接、错误文字及是否能重现。
登录问题可使用“重新验证”检查会话；不要将验证码、账号密码或 Token 发到 Issue。
可在“设置与状态”选择“导出诊断”，分享前检查并移除个人信息，不上传账号目录、会话文件或下载的媒体。
如资源不可用，先核对账号和地区；不要仅凭一次网络错误反复重装或删除会话。

自动测试不保证每个真实账号或设备都通过验收。第三方材料状态见[核查清单](compliance/native-2.0-status.md)。
