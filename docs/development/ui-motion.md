# UI 动效维护

桌面界面采用克制、响应明确的 Corporate 风格：小幅移动与透明度结合，不弹跳、不视差、不改变原有排版。动效只提供反馈，不参与下载、播放、认证或导航的业务状态判断。

## 入口与节奏

- `src/renderer/native-motion.js`：浏览器原生 Web Animations 控制器，无第三方运行时依赖。
- `src/renderer/native-motion.css`：悬停、按压、导航标记、处理反馈与系统减少动效样式。
- 主窗口和登录窗口通过本地资源加载；新增资源需同时维护 `electron/native-package.js` 的 UI 清单。

| 类型 | 时长 | 表现 |
| --- | --- | --- |
| 控件反馈 | 140ms，按压 80ms | 颜色与轻微缩放 |
| 状态反馈 | 200ms | 4px 位移与透明度 |
| 卡片/内容组 | 260ms | 10px 位移与透明度 |
| 侧栏/播放器/登录面板 | 340ms | 8px 位移与轻微缩放 |
| 页面切换 | 420ms | 前进/返回方向对应的 8px 横向位移 |

主要缓动为 `cubic-bezier(.2,0,0,1)`。只有旋转指示和进度条使用线性变化；进度条仍取真实状态，不能用动画伪造下载完成。

## 行为约束

1. 不 `await` 动画完成再执行操作。隐藏、删除、取消和停止播放立即生效，不等待退场效果。
2. 快速切页取消旧动画；移除或保存到返回快照的节点要先取消相关动画，不能保留脱离文档的动画引用。
3. 每次最多编排三个可见内容组，间隔 45ms。不为超大歌单的每一行逐个创建动画。
4. 轮询不重建按钮、不重复播放内容入场。反馈内容或任务状态真正变化时才触发对应反馈。
   下载页只对页标题和任务文字做入场，不移动任务卡片及其操作按钮，保证快速点击、按下到抬起及幂等删除仍稳定。
5. 系统 `prefers-reduced-motion` 开启时禁用空间动效，立即取消进行中的 Web Animations。窗口隐藏时停止动效。
6. 处理状态的装饰效果是有限次数的；持续的等待仍由文本、禁用状态和 `aria-busy` 表达。不要追加无限循环、全局 `transition: all` 或长期 `will-change`。
7. 不在动效中改变账号、下载队列或缓存逻辑，不加载远端脚本，也不绕过 CSP。

## 回归

```powershell
npm test
npm run test:web -- e2e/native-motion.spec.cjs
npm run test:web -- e2e/native-shell.spec.cjs e2e/native-jobs.spec.cjs
```

测试覆盖快速导航取消、悬停/按压、轮询稳定性、删除操作、登录面板及运行中切换减少动效。视觉检查使用合成封面与隔离状态，不依赖真实账号或商业媒体。
